# 04 — DOM → p5 Sketch Lab (Track 2, in-class lab)

**Used for:** the "Exercises to modify DOM elements and use those to
influence p5 sketch behaviour — invite creative play" session.
Directly follows the demo in `03-svelte-p5-demo/` — same
`P5Canvas.svelte` wrapper, same pattern, so nothing new to learn
before starting.

## Running it
```
npm install
npm run dev
```
One working example (a size slider) plus TODO comments in
`src/App.svelte`. Full brief and starting-point suggestions in
`lab-instructions.md`.

## Facilitation notes
- Deliberately open-ended — `lab-instructions.md` gives four
  suggested starting points (shape count, shape type, background
  colour, spin toggle) but frames them as options, not a checklist.
  Resist tightening this into a fixed spec even if asked.
- The one working example exists so no one is staring at a blank
  file — point students at it as the pattern to copy, not something
  to preserve unchanged.
- Reflection questions at the end of `lab-instructions.md` are meant
  to surface in the group discussion afterwards — worth collecting
  answers verbally rather than treating as a written submission.
